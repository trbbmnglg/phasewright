# Phasewright

Skills, agents and plugins that keep AI-assisted coding work small, checked and reversible. Ask an AI coding assistant for a big change and it tends to build it all in one go, skip checks, lose the plan between sessions and ship with no way back; Phasewright keeps the work small, checked and reversible ([README](https://github.com/trbbmnglg/phasewright/blob/main/README.md)).

This wiki describes what has shipped. Each page links the file its claims come from.

## Features

- [Phased shipping](Phased-shipping): the plugin that plans work as small phases with one deploy each.
- [Free resources](Free-resources): the report-only plugin that shows how pressured your machine is.
- [The guard](The-guard): the hook that keeps each phased-shipping agent inside its job.
- [Approval check](Approval-check): approval bound to the commands you saw at the preview.
- [Roadmap standard](Roadmap-standard): one roadmap format, with a check and a standardize command that writes only after you say yes.
- [Onboarding](Onboarding): the first run in a project, which lists what it would read, reads nothing until you confirm and never opens source code or credential files.
- [Dashboard](Dashboard): one local page that shows each project, its running sessions and the loops back in a phase, rebuilt at every step and making no network request.
- [Phase history and estimates](Phase-history-and-estimates): what each shipped phase records and how it calibrates the next estimate.
- [Library skills and agents](Library-skills-and-agents): the Markdown skills and agents, and the catalogue that lists them.
- [Security policy](Security-policy): how to report a vulnerability.
